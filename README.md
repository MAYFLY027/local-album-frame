# Local Album Frame · 本地电子相框

一个基于 mpv 的 Windows 电子相框配置项目：图片和视频混播、跨目录播放、时钟日期星期叠加。使用原有 Windows 文件夹，不要求 Docker 或网页服务。

**这是独立的启动工具、配置和时钟脚本项目，播放引擎是 mpv，不是从零编写的播放器。** mpv 以及所用依赖遵循各自许可证。

## 功能

- 启动时递归读取指定目录及子目录中的文件名，包含以后新增的文件夹。
- 图片默认显示30秒；视频按自身时长播放。默认静音，按 M 可切换。
- 顺序/随机、整组循环、全屏等比显示、缩放。
- 时间精确到秒，显示日期和星期；每换一张图片/视频，在四个角中选择不同位置。
- 时钟只使用本机时间。不联网、不上传媒体、不生成视频缩略图、不批量探测视频。
- 全部配置随项目目录保存；播放列表运行结束后清理。
- 简体中文设置窗口：选择目录、随机/顺序、图片间隔、视频、声音和时钟。针对Windows平板使用大按钮、可滑动设置页面。
- 播放画面默认隐藏按钮；轻点画面即可直接展开“上一项、暂停/继续、下一项、设置、声音、退出相册”全部大按钮，再点空白画面隐藏，没有常驻菜单按钮。
- 可在播放前勾选左上角图片信息文字：序号/总数、文件名、原始宽高和修改日期。信息只对当前文件做一次本地文件属性查询。
- 视频底部只显示约4像素高的进度线；点底部进度区域展开拖动条。拖动时显示目标位置，松手只跳转一次，约3秒后自动收回。首次展开后有10秒时间定位圆点；轻点其他画面也可关闭。

## 本地使用

1. Windows x64，准备一个可读的照片/视频目录。网盘须先由挂载软件提供本地路径。
2. 运行 `Install-Mpv.ps1`，或将来自可信来源的 mpv Windows 完整构建解压到 `player/`，确保有 `player/mpv.exe`。
3. 运行 `Build-UI.ps1` 用Windows附带的.NET Framework编译中文设置程序；`Settings.ps1` 也会在首次运行时自动编译。编译产物位于 `ui/AlbumSettings.exe`。在中文窗口里选择相册目录和播放设置，点击“保存并开始播放”。也可复制 `settings.example.json` 为 `settings.json` 手动配置。
4. 运行 `Create-Shortcuts.ps1` 生成设置和直接播放入口；`-Desktop` 生成的主入口会先打开中文设置。
5. 每次开始播放会读取目录，请稍候。播放中点击“设置”会暂停当前内容；关闭设置窗口可返回，保存后会按新设置重新开始播放。

重复启动同一安装目录时，新版会通过本机命名管道关闭旧播放实例，再启动新设置，不会让两个视频同时播放。命名管道不开放网络端口。

安装和播放快捷方式使用 Windows PowerShell。快捷方式上的 ExecutionPolicy Bypass 只作用于该次进程，不更改系统策略。

## 操作

| 操作 | 按键 |
| --- | --- |
| 暂停/继续 | 空格，或点击底部按钮 |
| 设置 | S，或点击“设置” |
| 显示/隐藏全部大按钮 | 轻点空白画面，或右键；没有常驻菜单按钮 |
| 视频进度 | 点底部细线附近展开，拖动圆点后松手跳转 |
| 上/下一项 | 左/右方向键，或滚轮 |
| 全屏切换 | F |
| 退出 | Esc |
| 静音切换 | M |
| 随机重排当前播放列表 | R |
| 隐藏/显示时钟 | C |
| 缩放 | Ctrl+滚轮 |
| 恢复原比例布局 | 0 |

为避免英文提示和过小的默认按钮，本项目关闭了 mpv 原有控制条，提供自己的中文触控按钮。相比 JPEGView，操作习惯和图片淡入淡出效果不同；本项目没有实现图片交叉淡入淡出或完整图片编辑器。

## 文件和隐私

- `settings.json`：本机路径和个人设置，已被 `.gitignore` 排除。
- `runtime/`：临时播放列表，包含个人文件路径，不应发布。
- `player/`：外部播放器与构建信息，不随源码发布。
- `ui/`：由本项目C#源码编译的中文设置程序，不随源码包提交；可在本地重建。
- 本项目只读源目录，不移动、改名、修改或删除媒体。文件夹内的重解析点不继续递归，避免循环与跳出指定范围。
- 播放视频会正常读取视频数据。该方案不提供“不触发网盘风控”的保证。
- 没有修改系统息屏设置，也不会阻止电脑锁屏。

## 发布到 GitHub

可以将本项目源码发布到自己的仓库，保留项目许可证和第三方说明。不要提交 `settings.json`、`runtime/`、`player/`、个人媒体或任何网盘凭据。代码和配置本身不包含网盘登录信息。

本项目没有自动创建仓库、推送、开启公开访问或上传媒体。发布前请自行审阅内容与仓库可见性。
